# Alibek Allanazarov

Frontend developer. I build web applications with React and TypeScript using the [Feature-Sliced Design](https://feature-sliced.design/) architecture and keep code consistent with strict linting, automated tests and documentation. I may look goofy, but my ESLint config is dead serious.

## Stack

- **Build:** [Vite](https://vite.dev/), [TypeScript](https://www.typescriptlang.org/)
- **UI:** [React](https://react.dev/), [Tailwind CSS](https://tailwindcss.com/)
- **Routing:** [TanStack Router](https://tanstack.com/router)
- **Data:** [TanStack Query](https://tanstack.com/query), [axios](https://axios-http.com/)
- **Tests:** [Vitest](https://vitest.dev/) (unit tests in Node.js and browser tests in Chromium), [MSW](https://mswjs.io/)
- **Code quality:** ESLint, Prettier, [Steiger](https://github.com/feature-sliced/steiger) (FSD checks), commitlint, husky, lint-staged
- **CI:** GitHub Actions, GitLab CI
